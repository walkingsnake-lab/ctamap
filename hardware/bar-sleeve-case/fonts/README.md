# Fonts for the case markings

Candidates for the debossed lettering on the shell's underside (`src/marks.py`, `MARK_FONT`), compared on
`coupon-marks-ladder.stl`. DejaVu Sans Bold (the default) comes from the system.

| File | Font | Source | License |
|---|---|---|---|
| `AtkinsonHyperlegible-Bold.ttf` | Atkinson Hyperlegible Bold (Braille Institute) | github.com/googlefonts/atkinson-hyperlegible | SIL OFL 1.1 (`AtkinsonHyperlegible-OFL.txt`) |
| `B612-Bold.ttf` | B612 Bold (cockpit display font) | github.com/polarsys/b612 | SIL OFL 1.1 (`B612-OFL.txt`) |
| `OCRB.otf` | OCR-B, outlines by Z. Wagner from Norbert Schwarz's METAFONT (`ocrb10.otf`) | CTAN `fonts/ocr-b-outline` | free to use, modify and distribute (`OCRB-README.txt`) |
